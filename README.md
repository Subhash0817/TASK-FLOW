# 🚀 TaskFlow

A modern full-stack productivity and task management web application built with **HTML, CSS, JavaScript, Flask, and SQLite**.

TaskFlow helps users organize their daily work, manage tasks efficiently, and improve productivity through a clean, responsive, and modern interface.

---

# ✨ Features

### Authentication
- ✅ User Login
- ✅ User Logout
- 🚧 User Signup (UI Ready)
- ✅ Remember Logged-in User

### Task Management
- ✅ Create Tasks
- ✅ Edit Tasks
- ✅ Delete Tasks
- ✅ Mark Tasks Complete
- ✅ Search Tasks
- ✅ Filter Tasks

### Productivity
- ✅ Progress Tracker
- ✅ Daily Goal

- ✅ Task Statistics

### Organization
- ✅ Categories
- ✅ Priority Levels

### User Interface

- ✅ Dark Mode

- ✅ Home Page

- ✅ Toast Notifications

### Backend

- ✅ Authentication API
