# TaskFlow

TaskFlow is a modern productivity and task management web application built using HTML, CSS, and JavaScript.

## Features

* Add, Edit, and Delete Tasks
* Daily Goal Tracking
* Streak System
* Progress Bar
* Priority Levels
* Due Dates
* Dark Mode
* Local Storage Persistence
* Task Filters (All, Active, Completed)
* Toast Notifications

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Local Storage

## Future Plans

* Achievement Badges
* Browser Notifications
* Task Categories
* Analytics Dashboard
* Python Backend (FastAPI)
* User Authentication
